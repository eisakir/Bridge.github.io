# Learn Bridge – A Beginner's Guide to Contract Bridge

A modern, responsive educational website designed to teach complete beginners the fundamentals of **Contract Bridge**.

The goal of this project is to help someone with **no previous Bridge experience** understand the game well enough to sit down and enjoy a friendly social game.

The site is built using only **HTML5**, **CSS3**, and **Vanilla JavaScript**, making it lightweight, fast, and easy to host on GitHub Pages.

---

## Features

### Beginner-Friendly Lessons

- Welcome introduction
- The four stages of Bridge
- Standard deck overview
- Partnerships
- Card ranking
- Suit ranking
- Auction mechanics
- Playing the hand
- Beginner scoring
- Glossary of common Bridge terms

---

### Interactive Features

- Responsive navigation
- Sticky header
- Active navigation highlighting
- Smooth scrolling
- Mobile navigation menu
- Scroll reveal animations
- 80-question Bridge knowledge bank
- 10 randomized questions per quiz attempt
- No repeated questions within an attempt
- Always-available button for starting a fresh randomized quiz
- Instant answer feedback
- Running score
- Final results screen
- Quiz restart button
- Back-to-top button
- Guided animated Bridge table lesson
- Dealing, dealer rotation, opening lead, dummy reveal, and trick animation
- Interactive 35-bid auction simulator
- Legal-bid enforcement, Pass, Double, Redouble, and declarer calculation
- Click-to-flip glossary cards with keyboard controls
- Interactive 13-card playground with drag-and-drop ordering
- Suit/rank sorting and randomized following-suit exercises

## Running Locally

No installation is required.

1. Download or clone this repository.

2. Open:

```text
index.html
```

in any modern web browser.

That's it.

No dependencies.

No frameworks.

No build tools.

---

## Deploying to GitHub Pages

1. Create a new GitHub repository.

2. Upload the project files.

3. Commit the changes.

4. Open:

```
Settings
```

↓

```
Pages
```

↓

Choose:

```
Deploy from Branch
```

↓

Select:

```
main
```

↓

```
/root
```

↓

Save.

GitHub Pages will publish the website automatically.
